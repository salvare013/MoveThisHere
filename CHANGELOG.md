## [1.1.0] - 2026-08-01

### Added

- Capacity slider now supports switching between **grams (g)** and **kilograms (kg)** via right-click menu.
- Default slider unit is **kg** with two decimal places; switch to **g** for integer gram precision.
- UI refreshes automatically when toggling units.
- Slider unit preference is persisted through save/load and copied by the Copy Settings tool.

### Changed

- Updated project metadata and added MIT license file.
- Added attribution to the original author [DoctorFeelGoodMD](https://github.com/DoctorFeelGoodMD) and the upstream [OxygenNotIncluded-Mods](https://github.com/DoctorFeelGoodMD/OxygenNotIncluded-Mods) repository.

## [1.0.0] - 2021

### Added

- Initial release of the Hauling Point building.
- 1×1 building for relocating liquids and gases.
- Right-click toggles: Auto-Bottle, Auto-Drop, Auto-Spill.
- Custom capacity slider with gram-level precision.
- Localization support for English and Chinese.
